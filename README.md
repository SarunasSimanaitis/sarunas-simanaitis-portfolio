# Šarūnas Simanaitis — Portfolio

A responsive portfolio built with semantic HTML, CSS, and vanilla JavaScript.

[View the live portfolio](https://sarunas-simanaitis-portfolio.vercel.app)

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. No build step or package installation is required.

## Project files

- `index.html` contains the portfolio content and project links.
- `styles.css` contains layout, colors, responsive styles, and motion.
- `script.js` handles the mobile navigation.
- `favicon.svg` is the browser tab icon.

The animations respect the device’s reduced-motion preference. The mobile menu supports keyboard navigation and Escape to close.
